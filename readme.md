
# 🎓 College Admission Strategist AI

An AI-powered college admission guidance web application built using Django and Google Gemini AI.

## Features

- Student Registration and Login
- Student Academic Profile Management
- Course Recommendations
- College Recommendations
- Gemini AI Admission Assistant
- Voice Input and Voice Response
- Chat History Management
- Personalized Student Dashboard

## Technologies Used

- Python 3.13
- Django
- SQLite
- Google Gemini AI
- HTML
- CSS
- JavaScript
- Speech Recognition API
- Text-to-Speech API

## Installation

1. Clone or download the project.
2. Create a virtual environment.
3. Install dependencies:

   pip install -r requirements.txt

4. Configure your `.env` file with:

   DJANGO_SECRET_KEY=your_secret_key
   GEMINI_API_KEY=your_gemini_api_key
   GEMINI_MODEL=your_model_name

5. Run migrations:

   python manage.py migrate

6. Start the server:

   python manage.py runserver

## Project Purpose

To help students explore suitable courses and colleges and receive AI-powered admission guidance.
